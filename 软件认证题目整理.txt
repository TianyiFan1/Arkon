一、通用踩坑提醒
================================================================
1. 方法名必须和平台 Main 调用处完全一致（如 freeOrder 不是 freeOrders，
   getTheMinWithColMaxs、characterSort、getMaxSendNumber 等），Java 区分大小写。
2. 框架默认通常只有 import java.util.List;，用到 Set/Map/HashMap/TreeMap/
   Comparator/Arrays/Collections 等必须自己补 import java.util.*;
3. 一定要用英文半角输入法：全角 ：；（） ，会导致
   illegal character '\uff1a' / '\uff1b' / '\uff08' 等报错。
4. 常见的字符混淆：数字 0 与字母 O；String 不是 string；
   Integer.MAX_VALUE 不是 Max_VALUE；success 不是 sucess。
5. 数值大、需要多次相加时用 long，避免 int 溢出（如 168*2^31）。
6. 不要注释掉无用代码（规范要求直接删除）；不要用 System.out 打印日志。
7. 提交前确认没有残留框架桩代码（如 return -1; 在方法体最前面，
   会导致 unreachable statement）。

----------------------------------------------------------------
题目 1：网元信息同步
----------------------------------------------------------------
描述：curTable（neId, neName, neFlag）与 bakTable（neId, neName）以 neId 为主键。
对 bakTable 中 curTable 不存在的 neId：新增，neFlag=0；
已存在的 neId：只更新 neName，neFlag 不变。
按 neId 升序输出同步后的 curTable。
输入：curTable，bakTable（各 0~50000 条）
输出：同步后的当前网元信息表
样例：[256,"NE256",1],[290,"NE290",0],[268,"26800000",1],[257,"NE257",1]
      + [273,"NE273"],[268,"NE268"],[257,"NE257"]
      -> [256..],[257..],[268,"NE268",1],[273,"NE273",0],[290..]

思路：
用 HashMap<Integer, CurTable> 以 neId 为键保存当前表记录；
遍历备份表：不存在则新建（neFlag=0），存在则只更新 neName。
最后按 neId 升序输出。

代码：
import java.util.*;

class Solution {
    List<CurTable> SyncNeInfo(List<CurTable> curTable, List<BakTable> bakTable) {
        Map<Integer, CurTable> map = new HashMap<>();
        for (CurTable cur : curTable) {
            map.put(cur.neId, cur);
        }
        for (BakTable bak : bakTable) {
            CurTable cur = map.get(bak.neId);
            if (cur == null) {
                CurTable add = new CurTable();
                add.neId = bak.neId;
                add.neName = bak.neName;
                add.neFlag = 0;
                map.put(bak.neId, add);
            } else {
                cur.neName = bak.neName;   // 只改名称，neFlag 不动
            }
        }
        List<CurTable> result = new ArrayList<>(map.values());
        result.sort(Comparator.comparingInt(c -> c.neId));
        return result;
    }
}

class BakTable {
    int neId;
    String neName;
}
class CurTable {
    int neId;
    String neName;
    int neFlag;
}

易错点：
- 已存在记录不能整体 put 新对象，否则 neFlag 会丢，必须只改字段；
- 新增记录 neFlag 才置 0；
- HashMap 无序，必须排序。

题目 2：日活月活统计
----------------------------------------------------------------
描述：日志格式 yyyy-mm-dd|client_ip|url|result（同月内，可能乱序）。
日活 = 当天访问 /login.do 且 success 的不同 ip 数；
月活 = 当月访问 /login.do 且 success 的不同 ip 数；
ip 归一化（1.01.001.1 与 1.1.1.1 视为同一地址）。
输出长度 32 的整数序列：[月活, 第1天日活, ..., 第31天日活]。
输入：logs（0 < length <= 50000，每条 <= 150 字符）
样例：["2020-02-01|192.168.218.218|/login.do|success", ...] -> [2,1,2,0,...]

思路：
只统计 url 为 /login.do 且 result 为 success 的日志；
ip 归一化（每段 parseInt 去前导 0）；
daySets[1..31] 与 monthSet 两个去重集合，同时 add。

代码：
import java.util.*;

class Solution {
    int[] getActiveUserNum(List<String> logs) {
        Set<String> monthSet = new HashSet<>();
        Set<String>[] daySets = new HashSet[32];
        for (int i = 1; i <= 31; i++) {
            daySets[i] = new HashSet<>();
        }
        for (String log : logs) {
            String[] f = log.split("\\|");
            if (!f[2].equals("/login.do") || !f[3].equals("success")) {
                continue;
            }
            int day = Integer.parseInt(f[0].substring(8, 10));
            String ip = normalizeIp(f[1]);
            daySets[day].add(ip);
            monthSet.add(ip);
        }
        int[] result = new int[32];
        result[0] = monthSet.size();
        for (int d = 1; d <= 31; d++) {
            result[d] = daySets[d].size();
        }
        return result;
    }

    String normalizeIp(String ip) {
        String[] seg = ip.split("\\.");
        return Integer.parseInt(seg[0]) + "." + Integer.parseInt(seg[1]) + "."
             + Integer.parseInt(seg[2]) + "." + Integer.parseInt(seg[3]);
    }
}

易错点：
- split("\\|") 必须转义；
- /to_login.do 不能用 contains 匹配，必须 equals；
- 月活不是日活相加（同一 ip 多天只算一次）。

题目 3：促销活动（免单）
----------------------------------------------------------------
描述：每一秒内最早的订单（可多个并列）免单，统计免单订单数。
订单时间格式 YYYY-MM-DD hh:mm:ss.fff。
输入：orderTime（1 <= length <= 50000）
输出：免单订单数
样例：["...00.001","...00.002","...00.003","...08:59:00.123",
       "...08:59:00.123","2018-12-28 13:08:00.999"] -> 4

思路：
每一秒内毫秒值最小的订单（可并列）免单；
先按秒统计最小毫秒，再数等于最小值的订单数。

代码：
import java.util.*;

class Solution {
    int freeOrder(List<String> orderTime) {
        Map<String, Integer> minFff = new HashMap<>();
        for (String t : orderTime) {
            String sec = t.substring(0, 19);
            int fff = Integer.parseInt(t.substring(20, 23));
            Integer old = minFff.get(sec);
            if (old == null || fff < old) {
                minFff.put(sec, fff);
            }
        }
        int cnt = 0;
        for (String t : orderTime) {
            String sec = t.substring(0, 19);
            int fff = Integer.parseInt(t.substring(20, 23));
            if (fff == minFff.get(sec)) {
                cnt++;
            }
        }
        return cnt;
    }
}

易错点：
- 不是全局最早，是每秒分别比；
- 并列最早都免单；
- 下标：秒 substring(0,19)，毫秒 substring(20,23)。

题目 4：公共字符
----------------------------------------------------------------
描述：找出在所有字符串中都至少出现 count 次的字符，按 ASCII 升序输出。
输入：count（1~100），strings（1~100 个，长度 <1000，仅字母数字）
输出：符合要求的字符列表，无则 []
样例：2, ["aabbccFFFFx2x2","aaccddFFFFx2x2","aabcdFFFFx2x2"]
      -> ["2","F","a","x"]

思路：
对每个字符，求它在所有字符串中出现次数的最小值；
最小值 >= count 即合格；按 0~127 遍历天然 ASCII 升序。
框架返回 char[]，所以先数个数再建数组。

代码：
import java.util.*;

class Solution {
    char[] commonChars(int count, List<String> strings) {
        int[] minCount = new int[128];
        Arrays.fill(minCount, Integer.MAX_VALUE);
        for (String s : strings) {
            int[] freq = new int[128];
            for (char c : s.toCharArray()) {
                freq[c]++;
            }
            for (int c = 0; c < 128; c++) {
                minCount[c] = Math.min(minCount[c], freq[c]);
            }
        }
        int size = 0;
        for (int c = 0; c < 128; c++) {
            if (minCount[c] >= count) size++;
        }
        char[] res = new char[size];
        int idx = 0;
        for (int c = 0; c < 128; c++) {
            if (minCount[c] >= count) {
                res[idx++] = (char) c;
            }
        }
        return res;
    }
}

易错点：
- freq 必须在字符串循环内新建，不能累积；
- minCount 初始 Integer.MAX_VALUE；
- 循环条件写 c < 128（写成 0 < 128 会死循环）。

题目 5：给定差值的组合
----------------------------------------------------------------
描述：数组元素唯一，求两个元素相减等于 diff 的不同无序组合个数。
输入：diff（-50000~50000），numbers（2~102400 个，-20~102400）
输出：组合个数
样例：3, [1,3,2,5,4] -> 2；-1, [1,2,3] -> 2

思路：
条件 a - b = diff，即对每个 a 查 a - diff 是否存在；
diff == 0 时元素唯一无组合，返回 0。

代码：
import java.util.*;

class Solution {
    int getDiffCnt(int diff, int[] numbers) {
        if (diff == 0) return 0;
        Set<Integer> set = new HashSet<>();
        for (int x : numbers) set.add(x);
        int cnt = 0;
        for (int a : numbers) {
            if (set.contains(a - diff)) cnt++;
        }
        return cnt;
    }
}

易错点：
- 查 a - diff 不是 a + diff；
- diff=0 必须特判。

题目 7：电话拦截
----------------------------------------------------------------
描述：白名单两种：精确号码、前缀号码（以 * 结尾）。
C 呼入：在白名单则接通，否则拒接；W 添加入白名单。
按号码首次呼入顺序输出 [号码, 接通次数, 拒接次数]。
输入：operations（1~100，["C"/"W", 号码]）
样例：[["C","13300000000"],["W","13144444444"],["C","13144444444"],...]
      -> [["13300000000",0,1],["13144444444",1,0],...]

思路：
精确白名单 Set；前缀白名单 List（去掉末尾 *）；
LinkedHashMap 统计号码，保持首次呼入顺序；
W 操作即时生效，必须按时间顺序处理。

代码：
import java.util.*;

class Solution {
    List<MyRecord> getPhoneRecords(List<Operation> operations) {
        Set<String> exact = new HashSet<>();
        List<String> prefixes = new ArrayList<>();
        Map<String, MyRecord> map = new LinkedHashMap<>();
        for (Operation op : operations) {
            if (op.opType == 'W') {
                if (op.number.endsWith("*")) {
                    prefixes.add(op.number.substring(0, op.number.length() - 1));
                } else {
                    exact.add(op.number);
                }
            } else {
                boolean allow = exact.contains(op.number);
                if (!allow) {
                    for (String p : prefixes) {
                        if (op.number.startsWith(p)) { allow = true; break; }
                    }
                }
                MyRecord r = map.get(op.number);
                if (r == null) {
                    r = new MyRecord();
                    r.number = op.number;
                    map.put(op.number, r);
                }
                if (allow) r.accepted++;
                else r.refused++;
            }
        }
        return new ArrayList<>(map.values());
    }
}

class Operation {
    char opType;
    String number;
}
class MyRecord {
    String number;
    int accepted;
    int refused;
}

易错点：
- 输出顺序是首次呼入顺序，必须 LinkedHashMap；
- 精确号码 equals/contains，前缀 startsWith；
- * 要截掉后再比较。

题目 8：矩阵列的最大值中的最小值
----------------------------------------------------------------
描述：先求每列最大值，再求这些最大值中的最小值。
输入：matrix（1~100 行，1~100 列，-10000~10000）
输出：所求整数
样例：[[1,2],[3,4],[2,4]] -> 3

思路：
按列求最大值，再对所有列最大值取最小。

代码：
class Solution {
    int getTheMinWithColMaxs(int[][] matrix) {
        int n = matrix.length;
        int m = matrix[0].length;
        int result = Integer.MAX_VALUE;
        for (int j = 0; j < m; j++) {
            int colMax = matrix[0][j];
            for (int i = 1; i < n; i++) {
                if (matrix[i][j] > colMax) colMax = matrix[i][j];
            }
            result = Math.min(result, colMax);
        }
        return result;
    }
}

易错点：
- colMax 用 matrix[0][j] 初始化，不能用 0（全负数会错）。

题目 9：字符排序
----------------------------------------------------------------
描述：位置类型不变（数字位仍是数字，字母位仍是字母）；
数字按 0-9 升序；字母中小写在前（a-z 升序），大写在后（A-Z 升序）。
输入：inputStr（1 <= length < 1000，仅字母数字）
输出：排序后的字符串
样例："a2CB1c" -> "a1cB2C"；"ab12C4Ac3B" -> "ab12c3AB4C"

思路：
数字和字母分开收集；数字升序；
字母：小写 a-z 在前，大写 A-Z 在后；按原位置类型回填。

代码：
import java.util.*;

class Solution {
    String characterSort(String inputStr) {
        List<Character> digits = new ArrayList<>();
        List<Character> letters = new ArrayList<>();
        for (char c : inputStr.toCharArray()) {
            if (Character.isDigit(c)) digits.add(c);
            else letters.add(c);
        }
        Collections.sort(digits);
        letters.sort(Comparator.comparingInt(c ->
                Character.isLowerCase(c) ? (c - 'a') : (c - 'A' + 26)));
        StringBuilder sb = new StringBuilder();
        int di = 0, li = 0;
        for (char c : inputStr.toCharArray()) {
            if (Character.isDigit(c)) sb.append(digits.get(di++));
            else sb.append(letters.get(li++));
        }
        return sb.toString();
    }
}

易错点：
- 不是整体排序，是分开排完按原位置回填；
- 大写排在小写后面。

题目 10：话单发送
----------------------------------------------------------------
描述：话单优先级值越小越高，高优先级发完才能发次优先级；
总长度不超过承载规格 cap；某优先级未发完则其后的都不能发。
输入：cap（1~10000），bills（长度 0~1000），priorities（0~30）
输出：最多可发送的话单数
样例：110, [50,20,30,10,50], [2,2,1,3,1] -> 3

思路：
按优先级分组（TreeMap 升序）；
整级总长 <= 剩余容量则全发；否则同级按长度升序贪心多发，
然后 break（低优先级全部禁止）。

代码：
import java.util.*;

class Solution {
    int getMaxSendNumber(int cap, int[] bills, int[] priorities) {
        Map<Integer, List<Integer>> map = new TreeMap<>();
        for (int i = 0; i < bills.length; i++) {
            map.computeIfAbsent(priorities[i], k -> new ArrayList<>()).add(bills[i]);
        }
        int count = 0;
        for (List<Integer> list : map.values()) {
            Collections.sort(list);
            int sum = 0;
            for (int x : list) sum += x;
            if (sum <= cap) {
                cap -= sum;
                count += list.size();
            } else {
                for (int x : list) {
                    if (x <= cap) { cap -= x; count++; }
                    else break;
                }
                break;
            }
        }
        return count;
    }
}

易错点：
- 某级没发完必须 break，后续级全部不能发；
- 同级发不完时按长度升序贪心。

题目 11：信号解码
----------------------------------------------------------------
描述：x@y = 2*x+y+3，x$y = 3*x+2*y+1；
@ 优先级高于 $，同级从左到右；x、y 为非负整数。
输入：message（3~100，仅数字和 @ $）
输出：计算结果
样例："11@2$3@14" -> 128；"103$104@105@2$106@107" -> 5397

思路：
按 $ 切段，每段内按 @ 从左到右折叠；
段结果再按 $ 从左到右合并；用 long 防溢出。

代码：
class Solution {
    int calculate(String message) {
        String[] parts = message.split("\\$");
        long result = 0;
        boolean first = true;
        for (String part : parts) {
            long seg = evalAt(part);
            if (first) { result = seg; first = false; }
            else result = 3 * result + 2 * seg + 1;
        }
        return (int) result;
    }
    private long evalAt(String part) {
        String[] nums = part.split("@");
        long acc = Long.parseLong(nums[0]);
        for (int i = 1; i < nums.length; i++) {
            long y = Long.parseLong(nums[i]);
            acc = 2 * acc + y + 3;
        }
        return acc;
    }
}

易错点：
- split("\\$") 必须转义 $；
- @ 段内左结合。

题目 12：内存空间长度
----------------------------------------------------------------
描述：每次初始化 [start, end)（左闭右开），允许重复初始化，求最终被初始化的总长度。
输入：cmdsOfMemInit（1~100000，[start,end]，0<=start<end<=10^9）
输出：总长度
样例：[[2,4],[3,7],[4,6]] -> 5；[[3,7],[2,4],[10,30]] -> 25

思路：
按起点排序，扫描合并重叠区间，累加长度。

代码：
import java.util.*;

class Solution {
    int getTotalMemLen4Init(List<RangeOfMem> cmdsOfMemInit) {
        cmdsOfMemInit.sort(Comparator.comparingInt(r -> r.start));
        long total = 0;
        long curStart = cmdsOfMemInit.get(0).start;
        long curEnd = cmdsOfMemInit.get(0).end;
        for (int i = 1; i < cmdsOfMemInit.size(); i++) {
            long s = cmdsOfMemInit.get(i).start;
            long e = cmdsOfMemInit.get(i).end;
            if (s <= curEnd) {
                curEnd = Math.max(curEnd, e);
            } else {
                total += curEnd - curStart;
                curStart = s;
                curEnd = e;
            }
        }
        total += curEnd - curStart;
        return (int) total;
    }
}
class RangeOfMem {
    int start;
    int end;
}

易错点：
- 循环结束必须结算最后一个区间；
- 合并用 max，防止被包含区间缩小范围。

题目 13：遥控小车
----------------------------------------------------------------
描述：初始 (0,0) 朝北（上为 +Y，右为 +X）；G 直走 1 格，L 左转 90，R 右转 90。
输入：cmds（1~100，仅 G/L/R）
输出：最终位置 [x, y]
样例："GG" -> [0,2]

思路：
方向索引 0=北 1=西 2=南 3=东；
L: (dir+1)%4，R: (dir+3)%4，G: 按方向移动。

代码：
class Solution {
    CoordPos runRemoteCtrlCar(String cmds) {
        int[] dx = {0, -1, 0, 1};
        int[] dy = {1, 0, -1, 0};
        int dir = 0, x = 0, y = 0;
        for (char c : cmds.toCharArray()) {
            if (c == 'G') { x += dx[dir]; y += dy[dir]; }
            else if (c == 'L') dir = (dir + 1) % 4;
            else dir = (dir + 3) % 4;
        }
        CoordPos pos = new CoordPos();
        pos.coordX = x;
        pos.coordY = y;
        return pos;
    }
}
class CoordPos {
    int coordX;
    int coordY;
}

易错点：
- 北是 +Y；初始朝北。

题目 14：重组乱序的数据分段
----------------------------------------------------------------
描述：分段格式 [数据类型, 分段序号, 结束标志, 内容长度, 净荷内容]；
筛选 dstType，去重；完整条件：序号从 0 连续，且仅最大序号的结束标志为 1。
能重组则按序号升序拼接净荷，否则输出 "NA"。
输入：dataFragments（1~1000000），dstType
样例：类型 0 的分段 -> "Sayhellotoworld"；缺序号 0 -> "NA"

思路：
筛选目标类型；Map<序号, 内容> 去重；
成功条件：size == maxSeq+1（0~max 连续）且 endFlag[maxSeq]==1；
按序号拼接，否则返回 "NA"。

代码：
import java.util.*;

class Solution {
    String recombine(List<DataFragment> dataFragments, int dstType) {
        Map<Integer, String> contentMap = new HashMap<>();
        Map<Integer, Integer> endMap = new HashMap<>();
        for (DataFragment f : dataFragments) {
            if (f.dataType != dstType) continue;
            contentMap.putIfAbsent(f.index, f.data);
            endMap.put(f.index, f.endFlag);
        }
        if (contentMap.isEmpty()) return "NA";
        int maxSeq = Collections.max(contentMap.keySet());
        if (contentMap.size() != maxSeq + 1) return "NA";
        if (endMap.get(maxSeq) != 1) return "NA";
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i <= maxSeq; i++) sb.append(contentMap.get(i));
        return sb.toString();
    }
}
class DataFragment {
    int dataType;
    int index;
    int endFlag;
    int len;
    String data;
}

易错点：
- 连续性判断 size == maxSeq+1；
- 无该类型数据返回 NA。

题目 15：字符编码（XUTF）
----------------------------------------------------------------
描述：编号值 0~2^31-1，按范围用 1~6 字节编码：
1字节 1xxxxxxx；多字节首字节前 n 位为 0、第 n+1 位为 1，
后续字节前两位为 01，其余为有效位（右侧对齐、左侧补 0）。
输入：unicodeVal（0 <= val < 2^31）
输出：大写十六进制字符串
样例：21326 -> "154D4E"；34 -> "A2"；1225859 -> "0C6B5243"

思路：
按范围定字节数 n；首字节有效位 7-n，后续每字节 6 位；
n=1 直接 0x80|val；每字节 %02X 拼接。

代码：
class Solution {
    String xutfEncoding(int unicodeVal) {
        long val = unicodeVal;
        int n;
        if (val < (1L << 7)) n = 1;
        else if (val < (1L << 11)) n = 2;
        else if (val < (1L << 16)) n = 3;
        else if (val < (1L << 21)) n = 4;
        else if (val < (1L << 26)) n = 5;
        else n = 6;
        StringBuilder sb = new StringBuilder();
        if (n == 1) {
            sb.append(String.format(java.util.Locale.ROOT, "%02X", 0x80 | (int) val));
        } else {
            int firstBits = 7 - n;
            int shift = 6 * (n - 1);
            int first = (1 << firstBits) | (int) ((val >> shift) & ((1L << firstBits) - 1));
            sb.append(String.format(java.util.Locale.ROOT, "%02X", first));
            for (int k = n - 2; k >= 0; k--) {
                int chunk = (int) ((val >> (6 * k)) & 0x3F);
                sb.append(String.format(java.util.Locale.ROOT, "%02X", 0x40 | chunk));
            }
        }
        return sb.toString();
    }
}

易错点：
- 首字节标志位是 1<<(7-n)；
- 后续字节前缀 01 即 0x40。

题目 16：编码格式校验（XUTF 解码）
----------------------------------------------------------------
描述：1 字节 0xxxxxxx；多字节首字节前 n 位为 1、第 n+1 位为 0，
后续字节前两位 10；有效位拼接为编号值。合法返回编号值，否则 -1。
输入：encodedString（2~12，偶数长度，0-9A-F）
输出：编号值或 -1
样例："E980A5" -> 36901；"C0C0" -> -1

思路：
首字节最高位 0 → n=1；
否则数前导 1 的个数作为 n，n 必须在 [2,6]；
总字节数必须等于 n；后续字节必须满足 (b & 0xC0) == 0x80；
有效位拼接得编号值，否则 -1。

代码：
class Solution {
    int decodeChar(String encodedString) {
        int totalBytes = encodedString.length() / 2;
        int[] bytes = new int[totalBytes];
        for (int i = 0; i < totalBytes; i++) {
            bytes[i] = Integer.parseInt(encodedString.substring(i * 2, i * 2 + 2), 16);
        }
        int first = bytes[0];
        if ((first & 0x80) == 0) {
            if (totalBytes != 1) return -1;
            return first & 0x7F;
        }
        int n = 0;
        int t = first;
        while ((t & 0x80) != 0) {
            n++;
            t = (t << 1) & 0xFF;
        }
        if (n < 2 || n > 6) return -1;
        if (totalBytes != n) return -1;
        int mask = (1 << (7 - n)) - 1;
        long val = first & mask;
        for (int i = 1; i < n; i++) {
            if ((bytes[i] & 0xC0) != 0x80) return -1;
            val = (val << 6) | (bytes[i] & 0x3F);
        }
        return (int) val;
    }
}

易错点：
- 10xxxxxx 不能当首字节（n=1 只允许最高位为 0），必须返回 -1；
- 长度必须等于 n。

题目 17：简易校验和算法
----------------------------------------------------------------
描述：字节数非 4 的倍数时尾部补 0xFF（最多 3 个）；
每 4 字节为一组，依次异或，结果为校验和。
输入：十六进制字符串（长度 2~200）
输出：固定 8 位大写十六进制
样例："61626364323031324C6162" -> "1F3330A9"；
      "41" -> "41FFFFFF"；"687561776569" -> "0D1C9E88"

思路：
每 2 个 hex 字符为 1 字节；补 0xFF 到 4 的倍数；
每 4 字节大端拼 int，依次异或；%08X 输出。

代码：
class Solution {
    String simpleCheckSum(String inputStr) {
        int len = inputStr.length() / 2;
        int totalBytes = ((len + 3) / 4) * 4;
        int checksum = 0;
        for (int i = 0; i < totalBytes; i += 4) {
            int word = 0;
            for (int j = 0; j < 4; j++) {
                int idx = i + j;
                int b = (idx < len)
                        ? Integer.parseInt(inputStr.substring(idx * 2, idx * 2 + 2), 16)
                        : 0xFF;
                word = (word << 8) | b;
            }
            checksum = (i == 0) ? word : (checksum ^ word);
        }
        return String.format(java.util.Locale.ROOT, "%08X", checksum);
    }
}

易错点：
- 只有最后一组可能含补齐的 0xFF；
- 输出固定 8 位大写，前导 0 用 %08X。

题目 18：路由表最长匹配
----------------------------------------------------------------
描述：路由 entryIp/m，前 m 位相同即匹配；0.0.0.0/0 匹配所有；
取最长匹配（m 最大），多条同长取最先给出的；无匹配输出 "empty"。
输入：dstIp，ipTable（1~10000）
输出：最长匹配的路由或 "empty"
样例："192.168.0.3", ["10.166.50.0/23","192.0.0.0/8","10.255.255.255/32",
      "192.168.0.1/24","127.0.0.0/8","192.168.0.0/24"] -> "192.168.0.1/24"

思路：
IP 转 long；m=0 掩码为 0；
(dst & mask) == (entry & mask) 则匹配；
取最大 m，m 相同保留先出现的。

代码：
import java.util.*;

class Solution {
    String routerSearch(String dstIp, List<String> ipTable) {
        long dst = ipToLong(dstIp);
        long bestM = -1;
        String best = "empty";
        for (String route : ipTable) {
            String[] parts = route.split("/");
            long entryIp = ipToLong(parts[0]);
            int m = Integer.parseInt(parts[1]);
            long mask = (m == 0) ? 0L : (0xFFFFFFFFL << (32 - m));
            if ((dst & mask) == (entryIp & mask)) {
                if (m > bestM) {
                    bestM = m;
                    best = route;
                }
            }
        }
        return best;
    }
    private long ipToLong(String ip) {
        String[] p = ip.split("\\.");
        long res = 0;
        for (String s : p) res = (res << 8) | Integer.parseInt(s);
        return res;
    }
}

易错点：
- m=0 必须特判（long 左移 32 位行为异常）；
- 用严格大于保证同长度保留先出现的。

题目 19：SQL 解析执行（MiniDb）
----------------------------------------------------------------
描述：create(tableId, colNum, keys)：建表，列名 a 起始；keys 为主键列组合；
insert(tableId, values)：主键冲突则忽略；
select(tableId, conditions)：条件格式 a=25，条件之间为 AND，
按主键列顺序升序输出结果集。
输入：累计调用 <= 30000；表 <= 1000 个，每表 <= 1000 条记录
样例：create(1,3,"a") + 三条 insert + select(1,["b=5","c=6"]) -> [[4,5,6]]

思路：
Map<tableId, Table>；
主键值按 keys 顺序拼字符串用作 Map key，天然去重；
select 逐行校验所有条件（AND），再按主键列顺序排序。

代码：
import java.util.List;
import java.util.*;

class MiniDb {
    private Map<Integer, Table> tables = new HashMap<>();
    MiniDb() {
    }
    void create(int tableId, int colNum, String keys) {
        if (tables.containsKey(tableId)) return;
        Table t = new Table();
        t.colNum = colNum;
        t.keyIdx = new int[keys.length()];
        for (int i = 0; i < keys.length(); i++) {
            t.keyIdx[i] = keys.charAt(i) - 'a';
        }
        tables.put(tableId, t);
    }
    void insert(int tableId, int[] values) {
        Table t = tables.get(tableId);
        String key = buildKey(t, values);
        if (t.rows.containsKey(key)) return;
        t.rows.put(key, values.clone());
    }
    int[][] select(int tableId, List<String> conditions) {
        Table t = tables.get(tableId);
        List<int[]> matched = new ArrayList<>();
        outer:
        for (int[] row : t.rows.values()) {
            for (String cond : conditions) {
                int col = cond.charAt(0) - 'a';
                int val = Integer.parseInt(cond.substring(cond.indexOf('=') + 1));
                if (row[col] != val) continue outer;
            }
            matched.add(row);
        }
        matched.sort((a, b) -> {
            for (int idx : t.keyIdx) {
                if (a[idx] != b[idx]) return Integer.compare(a[idx], b[idx]);
            }
            return 0;
        });
        int[][] res = new int[matched.size()][];
        for (int i = 0; i < matched.size(); i++) res[i] = matched.get(i);
        return res;
    }
    private String buildKey(Table t, int[] values) {
        StringBuilder sb = new StringBuilder();
        for (int idx : t.keyIdx) sb.append(values[idx]).append(',');
        return sb.toString();
    }
    static class Table {
        int colNum;
        int[] keyIdx;
        Map<String, int[]> rows = new HashMap<>();
    }
}

易错点：
- 主键是 keys 中列顺序的组合，排序也按该顺序；
- 任一条件不满足要跳过整行（continue outer）。

题目 20：简易 DHCP 服务器
----------------------------------------------------------------
描述：地址池 192.168.0.0 ~ 192.168.0.255。
request(mac)：已分配则返回原 IP；曾申请且已释放则优先返回最近一次 IP；
否则先分配从未用过的、再分配已释放的（升序），都无则 "NA"。
release(mac)：已分配返回 true 并释放，否则 false。
输入：累计调用 <= 2000
样例：request AABB -> "192.168.0.0"；release -> true

思路：
assigned: 当前已分配；lastIp: 最近一次分配（释放后保留）；
everUsed: 是否曾分配过；inUse: 当前是否占用。
request：
1) 已分配 → 原 ip；
2) 曾申请且已释放 → 优先 lastIp（若空闲）；
3) 否则先找从未用过的，再找已释放的，按升序；都不行 → NA。
release：没分配返回 false，否则释放（保留 lastIp）。

代码：
import java.util.*;

class DHCPServerSys {
    private Map<String, Integer> assigned = new HashMap<>();
    private Map<String, Integer> lastIp = new HashMap<>();
    private boolean[] everUsed = new boolean[256];
    private boolean[] inUse = new boolean[256];
    DHCPServerSys() {
    }
    String request(String mac) {
        if (assigned.containsKey(mac)) return ipToString(assigned.get(mac));
        if (lastIp.containsKey(mac)) {
            int last = lastIp.get(mac);
            if (!inUse[last]) {
                allocate(mac, last);
                return ipToString(last);
            }
        }
        for (int i = 0; i < 256; i++) {
            if (!everUsed[i]) { allocate(mac, i); return ipToString(i); }
        }
        for (int i = 0; i < 256; i++) {
            if (everUsed[i] && !inUse[i]) { allocate(mac, i); return ipToString(i); }
        }
        return "NA";
    }
    boolean release(String mac) {
        Integer ip = assigned.remove(mac);
        if (ip == null) return false;
        inUse[ip] = false;
        return true;
    }
    private void allocate(String mac, int ip) {
        everUsed[ip] = true;
        inUse[ip] = true;
        assigned.put(mac, ip);
        lastIp.put(mac, ip);
    }
    private String ipToString(int ip) {
        return "192.168.0." + ip;
    }
}

易错点：
- 必须区分“从未用过”和“已释放”；
- release 不清 lastIp；
- 再申请时若 lastIp 已被别人占用要回退正常分配。

题目 21：简易内存池
----------------------------------------------------------------
描述：MemSystem(space) 初始化；request(size) 分配连续内存、低地址优先，
成功返回首地址，size=0 或空间不足返回 -1；
release(addr) 释放以该首地址开始的块，成功 true，否则 false。
输入：累计调用 <= 100
样例：MemSystem(100); request(10)->0; request(20)->10;
      release(0)->true; request(20)->30; request(10)->0

思路：
TreeMap<首地址, 大小> 存已分配块；
request 按地址升序扫描空隙（首次适配、低地址优先），含尾部空隙；
release 只按首地址作为 key 删除。

代码：
import java.util.*;

class MemSystem {
    private final int totalSpace;
    private final TreeMap<Integer, Integer> blocks = new TreeMap<>();
    MemSystem(int space) {
        this.totalSpace = space;
    }
    int request(int size) {
        if (size == 0) return -1;
        int prev = 0;
        for (Map.Entry<Integer, Integer> e : blocks.entrySet()) {
            int addr = e.getKey();
            if (addr - prev >= size) {
                blocks.put(prev, size);
                return prev;
            }
            prev = addr + e.getValue();
        }
        if (totalSpace - prev >= size) {
            blocks.put(prev, size);
            return prev;
        }
        return -1;
    }
    boolean release(int addr) {
        if (blocks.containsKey(addr)) {
            blocks.remove(addr);
            return true;
        }
        return false;
    }
}

易错点：
- 中间地址天然不是 key，释放返回 false；
- 已释放的块已被移除，二次释放返回 false；
- 不用手动合并空闲，扫描时由相邻块位置自然算出空隙。

题目 22：基站信号地图
----------------------------------------------------------------
描述：rows*cols 矩阵，基站覆盖上下左右及对角（8 邻域），每有一个基站
覆盖范围内每格信号 +1。操作 add（已存在则忽略）、delete（清除该格及
3x3 邻域内基站）。求最终非基站格的信号强度之和。
输入：rows, cols（1~100），baseStations（0~100），oprations（0~100）
样例：4,6,[[2,2],[3,3],[4,4]],[["delete",4,3],["add",1,2],["delete",2,5]] -> 11

思路：
布尔矩阵模拟 add（幂等）和 delete（3x3 九宫格清除）；
再给每个基站的 8 个邻居 +1；
遍历非基站格累加。

代码：
import java.util.*;

class Solution {
    int sumSignalStrength(int rows, int cols, int[][] baseStations, List<Operation> oprations) {
        boolean[][] station = new boolean[rows + 2][cols + 2];
        for (int[] b : baseStations) station[b[0]][b[1]] = true;
        for (Operation op : oprations) {
            if (op.opCode.equals("add")) {
                station[op.row][op.col] = true;
            } else {
                for (int dr = -1; dr <= 1; dr++) {
                    for (int dc = -1; dc <= 1; dc++) {
                        station[op.row + dr][op.col + dc] = false;
                    }
                }
            }
        }
        int[][] strength = new int[rows + 2][cols + 2];
        for (int r = 1; r <= rows; r++) {
            for (int c = 1; c <= cols; c++) {
                if (station[r][c]) {
                    for (int dr = -1; dr <= 1; dr++) {
                        for (int dc = -1; dc <= 1; dc++) {
                            if (dr == 0 && dc == 0) continue;
                            strength[r + dr][c + dc]++;
                        }
                    }
                }
            }
        }
        int sum = 0;
        for (int r = 1; r <= rows; r++) {
            for (int c = 1; c <= cols; c++) {
                if (!station[r][c]) sum += strength[r][c];
            }
        }
        return sum;
    }
}
class Operation {
    String opCode;
    int row;
    int col;
}

易错点：
- delete 是 3x3 含自身，对角也要删；
- 数组开 rows+2 留边界，下标从 1 开始；
- 求和要排除基站格。

题目 23：四则运算表达式（后序遍历）
----------------------------------------------------------------
描述：给后序遍历形式（后缀表达式）的四则运算表达式，求结果（只输出整数部分）；
除法向零截断，不存在除零。
输入：expression（1 <= length < 50000，操作数与运算符逗号分隔）
输出：整数结果
样例："9,3,5,-,2,*,+" -> 5；"3,-3,-,2,/,10,-" -> -7

思路：
后缀表达式用栈；
操作数入栈；运算符弹两个（先弹右、后弹左），算完压回；
负数额长度 >1，只有单字符才是运算符；Java 整数 / 向零截断。

代码：
class Solution {
    int calc(String expression) {
        String[] tokens = expression.split(",");
        long[] stack = new long[tokens.length];
        int top = 0;
        for (String token : tokens) {
            if (token.length() == 1 && isOperator(token.charAt(0))) {
                long b = stack[--top];
                long a = stack[--top];
                long res;
                switch (token.charAt(0)) {
                    case '+': res = a + b; break;
                    case '-': res = a - b; break;
                    case '*': res = a * b; break;
                    default:  res = a / b; break;
                }
                stack[top++] = res;
            } else {
                stack[top++] = Long.parseLong(token);
            }
        }
        return (int) stack[0];
    }
    private boolean isOperator(char c) {
        return c == '+' || c == '-' || c == '*' || c == '/';
    }
}

易错点：
- 弹出顺序：先右后左，a - b 别写反；
- 负数 "-3" 是操作数。

题目 24：业务负载分配
----------------------------------------------------------------
描述：不同类型任务不能放同一服务器；某类型任务可在多台服务器；
最高负载 = 单台服务器任务数最大值；求最小的最高负载。
输入：serverNum（1~10^9），tasks（1~100000，每项 1~10^9，length <= serverNum）
输出：最小的最高负载
样例：5, [7,4] -> 3；8, [101,1,1,20,40] -> 34

思路：
二分最高负载 L；
某类型 t 个任务、单机上限 L 需 ceil(t/L) 台；
可行性：Σceil(tasks[i]/L) <= serverNum；L 越大越可行。

代码：
class Solution {
    int getMinLoad(int serverNum, int[] tasks) {
        long lo = 1, hi = 0;
        for (int t : tasks) hi = Math.max(hi, t);
        while (lo < hi) {
            long mid = (lo + hi) / 2;
            if (feasible(mid, serverNum, tasks)) hi = mid;
            else lo = mid + 1;
        }
        return (int) lo;
    }
    private boolean feasible(long load, int serverNum, int[] tasks) {
        long need = 0;
        for (int t : tasks) {
            need += (t + load - 1) / load;
            if (need > serverNum) return false;
        }
        return need <= serverNum;
    }
}

易错点：
- 全程用 long，防止 t + load - 1 溢出；
- 提前 need > serverNum 退出。

题目 25：最佳升级时间窗
----------------------------------------------------------------
描述：visitCnt 长度 168（一周每小时）；选连续 x 小时（可跨周期，x<=168），
窗口内访问量之和 <= cap，求最大的 x；多个最优取开始下标最小的。
输出 [开始下标, 结束下标]（周期内 0~167），不存在返回 [-1,-1]。
样例：cap=6 的长数组 -> [22,25]；cap=167 -> [167,165]；cap=200 -> [0,167]

思路：
数组视为环形（用 % n 或复制一份）；
滑窗保证：和 <= cap 且长度 <= n；
最大长度优先，同长保留最小起点；
结束下标 (start + len - 1) % n 需回绕。

代码：
class Solution {
    Window getBestWindow(int cap, int[] visitCnt) {
        int n = visitCnt.length;
        long limit = cap, sum = 0;
        int left = 0, bestLen = 0, bestStart = -1;
        for (int right = 0; right < 2 * n; right++) {
            sum += visitCnt[right % n];
            while (left <= right && (sum > limit || right - left + 1 > n)) {
                sum -= visitCnt[left % n];
                left++;
            }
            int len = right - left + 1;
            if (len > 0 && left < n && len > bestLen) {
                bestLen = len;
                bestStart = left;
            }
        }
        Window w = new Window();
        if (bestLen == 0) {
            w.start = -1;
            w.end = -1;
        } else {
            w.start = bestStart;
            w.end = (bestStart + bestLen - 1) % n;
        }
        return w;
    }
}
class Window {
    int start;
    int end;
}

易错点：
- 和用 long；
- 起点只考虑 < n；
- 结束下标要 % n（跨周期回绕）；
- 同长取最小起点（left 单调不减，严格大于更新即可）。

题目 26：九宫格输入法
----------------------------------------------------------------
描述：数字状态直接输出数字；英文状态下按同一键多次循环选字母，
按键被其它键或停顿符中断即输出；0 在英文状态为空格（按几次几个空格）；
# 切换状态；! 为停顿。
输入：inputStr（1~200，字符集 [0-9#!]）
输出：实际显示的字符串
样例："123" -> "123"；"#22!23044444411" -> "bad i."

思路：
状态机：english 标志、pendingKey、pressCount；
# 先提交再切换；! 提交；
英文状态 0 = 每按一次一个空格；
非 0 键同键累加次数，换键先提交；
字符 = map[key][(count-1) % len]；
循环结束、0、#、!、换键时都要提交。
注意：键 1 的映射按题库为 ",."（两次为 '.'）。

代码：
class Solution {
    String displayByKeydowns(String inputStr) {
        String[] map = {null, ",.", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
        boolean english = false;
        StringBuilder sb = new StringBuilder();
        int pendingKey = -1, pressCount = 0;
        for (char c : inputStr.toCharArray()) {
            if (c == '#') {
                if (pendingKey != -1) {
                    appendPending(sb, map, pendingKey, pressCount);
                    pendingKey = -1; pressCount = 0;
                }
                english = !english;
            } else if (c == '!') {
                if (pendingKey != -1) {
                    appendPending(sb, map, pendingKey, pressCount);
                    pendingKey = -1; pressCount = 0;
                }
            } else {
                int d = c - '0';
                if (!english) {
                    sb.append(c);
                } else {
                    if (d == 0) {
                        if (pendingKey != -1) {
                            appendPending(sb, map, pendingKey, pressCount);
                            pendingKey = -1; pressCount = 0;
                        }
                        sb.append(' ');
                    } else {
                        if (pendingKey == d) pressCount++;
                        else {
                            if (pendingKey != -1) appendPending(sb, map, pendingKey, pressCount);
                            pendingKey = d; pressCount = 1;
                        }
                    }
                }
            }
        }
        if (pendingKey != -1) appendPending(sb, map, pendingKey, pressCount);
        return sb.toString();
    }
    private void appendPending(StringBuilder sb, String[] map, int key, int count) {
        String chars = map[key];
        sb.append(chars.charAt((count - 1) % chars.length()));
    }
}

易错点：
- 末尾必须提交 pending，否则丢最后一个字符；
- 0 不循环累积，每次一个空格；
- 键 1 映射根据题库可能需要调整（"./" 等），以实际用例为准。

题目 27：单词统计
----------------------------------------------------------------
描述：'-' 为续行符（仅在行尾，最后一行无）：把下一行首个非空字符起的
余下部分拼到续行符左侧；不含续行符的行与下一行分隔。
单词为连续字母，其余字符均为分隔符。统计单词数。
输入：lines（1~25 行，每行 1~80 字符）
样例：["engineers , worldwide, ,.courses     part","y.. .vendors.",
      ",hell-","o"] -> 7

思路：
若逻辑行以 '-' 结尾：删掉 '-'，拼接下一行从首个非空格字符开始的部分；
拼接后仍以 '-' 结尾则继续；
每个逻辑行统计连续小写字母段数量。

代码：
import java.util.*;

class Solution {
    int getWordsCnt(List<String> lines) {
        List<String> segments = new ArrayList<>();
        int n = lines.size();
        int i = 0;
        while (i < n) {
            StringBuilder buf = new StringBuilder(lines.get(i));
            while (buf.length() > 0
                    && buf.charAt(buf.length() - 1) == '-'
                    && i + 1 < n) {
                buf.deleteCharAt(buf.length() - 1);
                i++;
                String next = lines.get(i);
                int p = 0;
                while (p < next.length() && next.charAt(p) == ' ') p++;
                buf.append(next.substring(p));
            }
            segments.add(buf.toString());
            i++;
        }
        int total = 0;
        for (String seg : segments) total += countInSegment(seg);
        return total;
    }
    private int countInSegment(String s) {
        int cnt = 0;
        boolean inWord = false;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c >= 'a' && c <= 'z') {
                if (!inWord) { cnt++; inWord = true; }
            } else {
                inWord = false;
            }
        }
        return cnt;
    }
}

易错点：
- 跳过下一行前导空格，但逗号/句号要保留；
- 连续续行要用 while 一直合并；
- 全空格行拼空串。

题目 28：挑选礼物
----------------------------------------------------------------
描述：礼物取值 1/2，栈顶为 presents[0]；员工队列 favorites[0] 为队首。
队首喜欢栈顶则拿走并离开；否则到队尾；直到一轮无人能拿为止。
返回无法获取礼物的员工数。
输入：favorites（1~100，1/2），presents（长度相同，1/2）
输出：无法获取礼物的人数
样例：[1,2,2,1,2], [2,1,1,2,1] -> 1

思路：
ArrayDeque 模拟员工队列；指针 p 表示栈顶；
队首匹配则出队、p++；
否则移到队尾，连续 skipped == queue.size() 时跳出（一轮无人可取）。

代码：
import java.util.*;

class Solution {
    int getUnselectedNum(int[] favorites, int[] presents) {
        Deque<Integer> queue = new ArrayDeque<>();
        for (int f : favorites) queue.addLast(f);
        int p = 0, skipped = 0;
        while (!queue.isEmpty() && p < presents.length) {
            if (queue.peekFirst() == presents[p]) {
                queue.pollFirst();
                p++;
                skipped = 0;
            } else {
                queue.addLast(queue.pollFirst());
                skipped++;
                if (skipped == queue.size()) break;
            }
        }
        return queue.size();
    }
}

易错点：
- 终止条件是 skipped == queue.size()，不是 p 到末尾；
- 成功取走后 skipped 归零。

题目 29：时长单位转换
----------------------------------------------------------------
描述：1 year = 22 month，1 month = 31 day，1 day = 24 hour，
1 hour = 60 minute，1 minute = 60 second。
转换为尽量大的单位，整数表示，跳过数值为 0 的单位。
输入："数值 单位"（如 "489607 minute"，转换前 < 10 year）
输出：转换后的结果（单空格分隔）
样例："489607 minute" -> "10 month 30 day 7 minute"；
      "530323200 second" -> "9 year"；"21 month" -> "21 month"

思路：
统一换成秒；按 year→month→day→hour→minute→second 贪心分解；
跳过数值为 0 的单位；单空格拼接。

代码：
class Solution {
    String UnitTransform(String inputStr) {
        String[] parts = inputStr.trim().split("\\s+");
        long value = Long.parseLong(parts[0]);
        String unit = parts[1];
        long totalSeconds = value * unitToSeconds(unit);
        String[] units = {"year", "month", "day", "hour", "minute", "second"};
        long[] secs = {58924800L, 2678400L, 86400L, 3600L, 60L, 1L};
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < units.length; i++) {
            long cnt = totalSeconds / secs[i];
            totalSeconds %= secs[i];
            if (cnt > 0) {
                if (sb.length() > 0) sb.append(' ');
                sb.append(cnt).append(' ').append(units[i]);
            }
        }
        return sb.toString();
    }
    private long unitToSeconds(String unit) {
        switch (unit) {
            case "year":   return 58924800L;
            case "month":  return 2678400L;
            case "day":    return 86400L;
            case "hour":   return 3600L;
            case "minute": return 60L;
            default:       return 1L;
        }
    }
}

易错点：
- 1 year = 22 month，1 month = 31 day；
- 0 值单位不输出。

题目 30：磁盘空间统计
----------------------------------------------------------------
描述：求满足以下条件的区间个数：长度在 [minLen, maxLen] 内，
且区间平均值 >= threshold。
输入：records（1~10000，0~10000），[minLen,maxLen]（1~1000，maxLen<=n），
      threshold（0~10000）
输出：区间个数
样例：[2,0,2,0,2], [2,4], 1 -> 8

思路：
平均值 >= threshold 等价于 区间和 >= threshold * 长度；
枚举长度 L，滑窗/前缀和统计满足的区间数。

代码：
class Solution {
    int countIntervals(int[] records, int[] range, int threshold) {
        int n = records.length;
        int minLen = range[0], maxLen = range[1];
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + records[i];
        int count = 0;
        for (int L = minLen; L <= maxLen; L++) {
            long need = (long) threshold * L;
            for (int i = L; i <= n; i++) {
                if (prefix[i] - prefix[i - L] >= need) count++;
            }
        }
        return count;
    }
}

易错点：
- 用乘法比较避免除法误差；
- 纯暴力 O(n*maxLen^2) 会超时，前缀和 O(n*maxLen)。

题目 31：收银台设计
----------------------------------------------------------------
描述：面额 1/5/10/50/100 元；初始有 1/5/10/50 元若干（100 元为 0）。
每笔 payments[i]=[price, paidCashes(5个张数)]：
付款 < price 失败退回收到的钱；= price 成功；
> price 时按找零张数最少找零，成功则收到的钱入收银台，
零钱不足则失败退回收到的钱。
输出收银结束后 5 个面额（从小到大）的剩余张数。
样例：[5,2,5,1], [[47,[0,0,0,0,1]],[2,[0,1,0,0,0]],[1,[1,0,0,1,0]]]
      -> [3,2,5,0,1]

思路：
收到的钱先入账（样例 1 第三笔证明收到的钞票可用于找零）；
change = 收款 - 价格；用大面额优先贪心找零（面额成倍数关系，张数最少）；
凑不齐则整体回滚（等价退回收到的钱）；付款不足直接失败。

代码：
import java.util.Arrays;
import java.util.List;

class Solution {
    private static final int[] DENOM = {1, 5, 10, 50, 100};
    int[] cashierResult(int[] initCashes, List<Payment> payments) {
        long[] cash = new long[5];
        for (int i = 0; i < 4; i++) cash[i] = initCashes[i];
        for (Payment p : payments) {
            long price = p.price;
            long[] paid = new long[5];
            long paidAmount = 0;
            for (int i = 0; i < 5; i++) {
                paid[i] = p.paidCashes[i];
                paidAmount += paid[i] * DENOM[i];
            }
            if (paidAmount < price) continue;
            long[] backup = cash.clone();
            for (int i = 0; i < 5; i++) cash[i] += paid[i];
            long change = paidAmount - price;
            long[] used = new long[5];
            long rem = change;
            for (int i = 4; i >= 0; i--) {
                long u = Math.min(cash[i], rem / DENOM[i]);
                used[i] = u;
                rem -= u * DENOM[i];
            }
            if (rem != 0) {
                cash = backup;
            } else {
                for (int i = 0; i < 5; i++) cash[i] -= used[i];
            }
        }
        int[] res = new int[5];
        for (int i = 0; i < 5; i++) res[i] = (int) cash[i];
        return res;
    }
}
class Payment {
    int price;
    int[] paidCashes;
}

易错点：
- 必须先入账再找零（否则样例 1 第三笔会失败）；
- 找零失败必须整体回滚，不能部分扣减；
- 初始 100 元数量为 0。

题目 32：应用进程统计（Top3）
----------------------------------------------------------------
描述：processes[i] = [appName, userName, cpuUsed, memUsed]。
筛选 selectedUsers 的进程 → 按 appName 分组累加 cpu/mem →
按 sortRules（"cpuUsed"/"memUsed"，可 0~2 个）依次降序，
全相等按 appName 升序 → 返回 Top3 appName（不足 3 个按实际）。
输入：processes（1~100），sortRules，selectedUsers
样例：[["Explorer","user1",6,1000],["chrome","user1",3,800],
      ["chrome","user1",4,200],["welink","user1",9,800],
      ["edge","user1",8,900],["app","u2",1,1]],
      ["memUsed","cpuUsed"], ["user1"] -> ["chrome","Explorer","edge"]

思路：
筛选 selectedUsers；按 appName 分组累加 cpu/mem；
按 sortRules 逐字段降序，全部相等按 appName 升序；取前 3。

代码：
import java.util.*;

class Solution {
    List<String> getTop3App(List<Process> processes, List<String> sortRules, List<String> selectedUsers) {
        Set<String> users = new HashSet<>(selectedUsers);
        Map<String, int[]> agg = new HashMap<>();
        for (Process p : processes) {
            if (!users.contains(p.userName)) continue;
            int[] a = agg.computeIfAbsent(p.appName, k -> new int[2]);
            a[0] += p.cpuUsed;
            a[1] += p.memUsed;
        }
        List<String> names = new ArrayList<>(agg.keySet());
        names.sort((x, y) -> {
            int[] a = agg.get(x);
            int[] b = agg.get(y);
            for (String rule : sortRules) {
                int va = rule.equals("cpuUsed") ? a[0] : a[1];
                int vb = rule.equals("cpuUsed") ? b[0] : b[1];
                if (va != vb) return Integer.compare(vb, va);
            }
            return x.compareTo(y);
        });
        int k = Math.min(3, names.size());
        return new ArrayList<>(names.subList(0, k));
    }
}
class Process {
    String appName;
    String userName;
    int cpuUsed;
    int memUsed;
}

易错点：
- 排序字段降序，appName 升序且大小写敏感；
- sortRules 可能为空，直接按 appName 排。

题目 33：比特翻转
----------------------------------------------------------------
描述：最多可反转 bits 中的一位，求最大连续 target 的个数。
输入：target（0 或 1），bits（1~10000，仅 0/1）
输出：最大连续 target 个数
样例：1, [0,1,1,0,1,0,1,0,0] -> 4；0, 全 0 -> 8

思路：
转化为：窗口内“非 target 元素”最多 1 个的最长窗口；
滑动窗口维护 nonTarget 计数。

代码：
class Solution {
    int findMaxConsecutiveBits(int target, int[] bits) {
        int left = 0, nonTarget = 0, ans = 0;
        for (int right = 0; right < bits.length; right++) {
            if (bits[right] != target) nonTarget++;
            while (nonTarget > 1) {
                if (bits[left] != target) nonTarget--;
                left++;
            }
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}

易错点：
- 全为 target 时答案为 n（无需翻转）。

题目 34：浏览历史
----------------------------------------------------------------
描述：BrowserHistorySys(homepage, maxCount)：当前页为 homepage，
历史最多缓存 maxCount 个页面；
visit(url)：与当前页相同则不变；否则清除前进记录、跳转并缓存，
超容量删除最早的；返回缓存页面数量；
back()/forward()：后退/前进一步，越界则停留，返回停留页 url。
输入：累计调用 <= 100，maxCount < 20
样例：BrowserHistorySys("w3.huawei.com",10); visit("google.com") -> 2;
      back() -> "w3.huawei.com"; forward() -> "google.com"

思路：
ArrayList 存历史，idx 指向当前页；
visit：与当前页相同则不变；否则删除 idx 之后（清前进记录）、追加、
超容量删最早（下标 0），当前页变最后一项，返回 size；
back/forward：越界则停留，返回当前页。

代码：
import java.util.*;

class BrowserHistorySys {
    private final List<String> history = new ArrayList<>();
    private final int maxCount;
    private int idx;
    BrowserHistorySys(String homepage, int maxCount) {
        this.maxCount = maxCount;
        history.add(homepage);
        this.idx = 0;
    }
    int visit(String url) {
        if (history.get(idx).equals(url)) return history.size();
        while (history.size() - 1 > idx) {
            history.remove(history.size() - 1);
        }
        history.add(url);
        if (history.size() > maxCount) history.remove(0);
        idx = history.size() - 1;
        return history.size();
    }
    String back() {
        if (idx > 0) idx--;
        return history.get(idx);
    }
    String forward() {
        if (idx < history.size() - 1) idx++;
        return history.get(idx);
    }
}

易错点：
- visit 相同 url 不清前进记录；
- 超容量删最早（0），不是删最旧的前进记录。

三、理论题答案速查
================================================================
1. 华为常量命名未遵循规范：B（NUM_FIVE）、C（NUM_5）
   理由：名称需表达业务含义，不能只是描述数值。

2. 用括号明确操作顺序，写法正确的：D
   if ((a && b) || c)
   （A、B 是多余括号；C 依赖了 == 高于 || 的默认优先级）

3. 方法描述错误的：A、D
   A：方法长度参考上限通常为 100 行（30 行过严）
   D：嵌套深度建议不超过 4 层（不是 5 层）

4. 单例模式错误示例问题：
   左上：构造器 protected 且在构造器里 new 自己 → 无限递归；
   右上：懒汉无锁 → 线程不安全（需 synchronized + volatile）；
   左下：实现 Serializable 未加重写 readResolve → 反序列化破坏单例；
   右下：实现 Cloneable 未阻止 clone → 克隆破坏单例。

5. 父类构造方法调用可被覆写的方法：C
   子类字段尚未初始化，可能 NullPointerException。

6. static 方法调用输出：C
   Dog woofer = new Dog();
   Dog nipper = new Basenji();
   输出 woof / woof（static 按声明类型静态绑定）。

7. 敏感异常：A（FileNotFoundException）、B（SQLException）
   （D IOException 过于通用，按题库不算敏感异常；C NPE 不敏感）

8. Lock 释放：正确写法 unlock 放 finally，lock() 放 try 之前
   （Lock 不是 AutoCloseable，不能用 try-with-resources 自动释放）。

9. 可以停止线程的方法：C Thread.interrupt()
   （isInterrupted/interrupted 只是查询；notify 与停止无关）

10. 多线程并发正确说法：A、B、C、D 全部
    能无锁不锁 / 能锁块不锁方法 / 能用对象锁不用类锁 / 多锁保持一致顺序。

11. 泛型正确说法：A、B
    C、D 把 PECS 写反：读取用 extends，写入用 super。

12. 带输出流和错误流的进程：D
    必须同时消费 stdout 和 stderr 再 waitFor，否则死锁。

13. 序列化说法不正确的：C
    （应与规范一致；A transient 正确，B serialPersistentFields 可用，
     D JSON 关闭 type/白名单正确）

14. ReDoS 防护：A、B、C、D 全部
    限制长度 / 避免复杂正则 / 减少分组 / 避免动态构建+白名单。

15. 防 SQL 注入：A、B、D
    （C 字符串拼接 SQL 是注入根源，禁止）

16. 正常业务处理日志用：B info

17. 日志打印正确说法：A、B、D
    （C 错误：日志应使用英文，避免编码/国际化/分析工具问题）

18. 集合初始化错误的：B
    ArrayList 默认容量为 10（JDK8 懒加载，首次 add 分配），不是 0。

19. finalize() 缺点：A、B、C、D 全部
    执行时间不可预期 / 性能低 / 移植性差 / 安全风险（可复活）。

20. 安全检查方法建议修饰符：A、B、C
    static / final / private（防覆写绕过）；synchronized 与安全校验无关。

21. SecurityManager 正确说法：B、C、D
    （A 错误：默认不安装）

22. 安全场景强随机数：B SecureRandom

23. 注释说法有误的：C
    （无用代码应直接删除，不应注释保留）
